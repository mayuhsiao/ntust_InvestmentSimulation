## 1. 成交價怎麼決定

### 一律以收盤價成交

**你不能指定價格。** 下單時系統會直接用當日（或最近一個交易日）的**收盤價**成交。

這跟真實下單不一樣，但對競賽來說是必要的：

- 全班用同一個價格，**比的是選股與時機的判斷，不是誰手快**
- 收盤價是客觀、可查證、事後不會變動的數字
- 每日結算時，每個人的持股都用同一個基準計價

### 「當日」是哪一天

系統採用的是**最後一個已經確認的收盤價**。

| 下單時間 | 成交價 |
|---|---|
| 平日 14:00 之後 | **當天**的收盤價 |
| 平日 09:00 之前 | 前一個交易日的收盤價 |
| 週六、週日 | **上週五**的收盤價 |
| 平日 09:00–14:00 | **不開放下單**（見下一節） |

下單畫面上一定會明確寫出「**YYYY-MM-DD 收盤價**」，那就是你的成交價。

### 美股與台股交易日不同步

美股的收盤時間是台灣時間的凌晨。如果台股今天有開盤、美股還沒收盤，系統會用**美股最近一個已收盤交易日**的價格，畫面上會標示「（該市場最近一個交易日）」。

## 2. 交易時間

### 盤中不開放下單

**平日 09:00～14:00 系統鎖住下單功能。**

| 時間 | 狀態 | 用哪一天的收盤價 |
|---|---|---|
| 平日 09:00–13:30 | 🔒 台股盤中 | — |
| 平日 13:30–14:00 | 🔒 收盤結算中 | — |
| 平日 14:00 – 隔日 09:00 | ✅ 開放 | **當日**收盤價 |
| 週六、週日 | ✅ 全天開放 | **上週五**收盤價 |
| 國定假日 | ✅ 開放（09:00–14:00 除外*） | 最近一個交易日 |

### 為什麼要這樣限制

因為競賽是用**收盤價**成交的。

> 假設現在是早上 10:30，台積電盤中大漲 5%。
> 如果這時候能下單，你會用**昨天的收盤價**買到一檔已經確定上漲的股票 ——
> 等於看著答案作答，穩賺不賠。

限制盤中下單是為了讓每個人在做決定時，面對的都是**一樣的未知**。

### 美股的時段是分開判斷的

系統會**針對每一檔股票所屬的市場**判斷是否開盤：

- 台股盤中（台灣時間 09:00–14:00）→ 只鎖台股
- 美股盤中（台灣時間深夜至凌晨）→ 只鎖美股

所以台股盤中你仍然可以交易美股，反之亦然。

> \* 國定假日若落在平日，系統仍會在 09:00–14:00 鎖住下單（程式無法自動判斷休市日）。老師可視需要暫時解除限制。

### 14:00 會自動解鎖

畫面每 30 秒重新判斷一次，時間一到就會自動開放，**不需要重新整理網頁**。

## 3. 台股規則

### 交易單位

| 單位 | 股數 |
|---|---|
| 1 張 | 1,000 股 |
| 零股 | 1～999 股 |

**可以買零股。** 對 2,000,000 元的本金來說，高價股（例如台積電）買零股是合理的策略。

### 交易成本

| 項目 | 費率 | 何時收 |
|---|---|---|
| **手續費** | 0.1425% | 買進、賣出**都收** |
| 最低手續費 | 20 元 | |
| **證交稅** | 0.3% | **只有賣出收** |

手續費與證交稅皆**無條件捨去到元**（與券商實務一致）。

```
買進應付 = 成交價 × 股數 + 手續費
賣出實收 = 成交價 × 股數 − 手續費 − 證交稅
```

### 實例：買進 1 張台積電 @ 2,410 元

```
成交金額 = 2,410 × 1,000            = 2,410,000
手續費   = 2,410,000 × 0.1425%      =     3,434
─────────────────────────────────────────────
應付金額                             = 2,413,434
```

### 實例：賣出 1 張台積電 @ 2,500 元

```
成交金額 = 2,500 × 1,000            = 2,500,000
手續費   = 2,500,000 × 0.1425%      =     3,562
證交稅   = 2,500,000 × 0.3%         =     7,500
─────────────────────────────────────────────
實收金額                             = 2,488,938
```

> 📌 **來回一趟的成本約 0.6%。** 股價要漲超過 0.6% 你才開始賺錢。
> 這就是為什麼**頻繁交易會吃掉報酬** —— 在「損益拆解」裡看得到累計手續費。

## 4. 美股規則

### 交易單位

美股以「**股**」為單位，沒有「張」的概念。

### 交易成本（模擬國內券商複委託）

| 項目 | 費率 | 何時收 |
|---|---|---|
| **手續費** | 0.5% | 買進、賣出都收 |
| 最低手續費 | 500 元（台幣，約 15 美元） | |
| **證交稅** | **無** | |

> 美股手續費比台股高很多，是因為模擬的是**國內券商的複委託**（透過台灣券商買美股）。
> 如果直接在海外券商開戶，手續費通常趨近於零 —— 這個差異本身就值得討論。

### 💱 匯率換算

你的帳戶是**台幣** 200 萬，但美股用**美元**報價。系統會用**成交當日的 USD/TWD 匯率**把所有金額換算成台幣。

```
成交金額（台幣） = 美元股價 × 股數 × 當日匯率
```

### 實例：買進 10 股 AAPL @ $326.57，匯率 31.464

```
成交金額 = 326.57 × 10 × 31.464     = 102,752 元
手續費   = 102,752 × 0.5%           =     513 元
─────────────────────────────────────────────
應付金額                             = 103,265 元
```

### ⚠️ 你的報酬率同時包含股價與匯率

這是投資美股最容易被忽略的地方。

| 情境 | 股價變動 | 匯率變動 | 你的實際報酬 |
|---|---|---|---|
| 股漲、台幣貶 | +5% | 台幣貶 2% | **約 +7%** 🎉 |
| 股漲、台幣升 | +5% | 台幣升 5% | **約 0%** 😐 |
| 股跌、台幣升 | −3% | 台幣升 3% | **約 −6%** 😱 |

> **匯率風險是真實存在的成本。** 買美股不是只看公司好不好，還要看台幣走勢。
> 這也是「國際經濟趨勢」這門課的核心議題之一。

畫面上的股價一律顯示**原幣**（`$326.57`），但市值、損益、排名一律是**台幣**。

## 5. 淨值與報酬率的計算

### 每日淨值

```
某日淨值 = 現金餘額 + Σ(各持股股數 × 該日收盤價)
```

美股持股會先乘上該日匯率換成台幣。

### 報酬率

```
報酬率 = (淨值 − 起始本金) ÷ 起始本金
```

**排名就是以報酬率排序。**

### 平均成本

採**含手續費的移動平均**：

```
平均成本 = 累計買進成本（含手續費） ÷ 持有股數
```

所以你的平均成本會**比實際成交價略高一點點**，那個差額就是手續費。

### 已實現 vs 未實現損益

| | 定義 |
|---|---|
| **已實現損益** | 賣出實收金額 − 賣出股數 × 平均成本。**賣掉才算數** |
| **未實現損益** | 目前市值 − 持有成本。帳面上的，還沒落袋 |

### 停牌或無報價時

個股當日若沒有報價（停牌、休市日不同步等），系統會沿用**前一個有報價的交易日**收盤價計價，不會讓資產憑空消失。

## 6. 買賣限制

| 限制 | 說明 |
|---|---|
| **不能超買** | 買進金額（含手續費）不得超過可用現金 —— **不能融資** |
| **不能超賣** | 賣出股數不得超過持股 —— **不能放空** |
| **交易日限制** | 交易日必須在競賽期間內 |
| **只能用最新交易日** | 學生不能回補歷史日期（老師可以，用於修正） |
| **撤銷期限** | 成交後 30 分鐘內可自行刪除，超過請找老師 |
| **紀錄不可竄改** | 交易紀錄只能新增與刪除，不能修改 |

## 7. 除權息的影響

系統使用的是**未還原股價**（與證交所、各大看盤軟體顯示的一致）。

這代表：

- 個股在競賽期間**除權息**時，股價會出現帳面上的跳空缺口
- 但模擬帳戶**不會收到股利**
- 所以那一天你會看到資產小幅減少

### 影響有多大

台股除權息高峰是 7～9 月，秋季班（9～12 月）大部分個股已經除完，影響通常很小。高股息 ETF（例如 0056、00878）是季配息，仍可能遇到。

### 怎麼處理

1. **接受它**：這是使用未還原價格的必然結果，全班一致，不影響公平性
2. **避開**：查詢個股的除息日，避開那段期間
3. **當作題目**：在課堂上討論「除權息前後該不該參與」本身就是很好的教材

## 8. 報價資料從哪裡來

| 用途 | 來源 |
|---|---|
| 台股日收盤價 | Yahoo Finance（上市 `.TW`、上櫃 `.TWO`）；備援為[證交所 STOCK_DAY](https://www.twse.com.tw/) |
| 台股代號清單 | [證交所 OpenAPI](https://openapi.twse.com.tw/) + [櫃買中心 OpenAPI](https://www.tpex.org.tw/openapi/) |
| 美股日收盤價 | Yahoo Finance |
| 美股代號搜尋 | Yahoo Finance search API |
| USD/TWD 匯率 | Yahoo Finance `TWD=X` 日收盤 |

全部都是**真實市場資料**，沒有任何模擬或虛構的報價。

系統會判斷各交易所的實際盤別，**尚未收盤的當日報價不會被當成收盤價使用**，確保同一天不同時間下單不會拿到不同價格。
