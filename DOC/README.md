## 這是什麼

一個給課堂使用的投資模擬競賽平台。每位同學拿到**相同的起始本金 2,000,000 元**，在指定期間內買賣**真實的台股與美股**。系統每天以**收盤價**結算所有人的資產淨值，並即時排名。

沒有虛擬報價、沒有假資料 —— 股價直接取自證券交易所、櫃買中心與 Yahoo Finance，手續費與證交稅也按照真實費率計算。你在這裡賺到或賠掉的，就是你在真實市場會遇到的結果。

## 30 秒快速上手

1. 打開 <https://emrd-invest.netlify.app/>
2. 點「**註冊新帳號**」→ 填學號、老師公布的**認證碼**、密碼、姓名
3. 進入「**交易下單**」→ 搜尋框輸入 `2330` 或 `AAPL` → **點選下拉選單中的那一列**
4. 填股數 → 按「確認買進」
5. 到「**排行榜**」看看自己第幾名

> ⚠️ 最常見的卡關：在搜尋框打完代號後**沒有點選下拉選單**，系統就不知道你要買哪一檔，「確認買進」會是灰色的。
